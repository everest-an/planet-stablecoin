# Planet — 一页纸（发行商 / 资金方版）

**The collateral layer for tokenized commodities.**
让代币化的大宗商品与商品 ETF 获得统一的抵押与融资能力。Planet 不发行资产、不托管底层——做接入、估值、抵押风控与撮合。

## 我们解决什么问题

持有代币化商品的人有资产但没有融资渠道；持有稳定币的人有资金但没有抵押品。发行商各自做借贷，规模小、风控重复。Planet 把两边接起来，并且**按数据质量给抵押品定价**——同一份黄金，在行情源降级时自动降低抵押率。

## 三种角色，各拿各的

| 角色 | 提供 | 得到 |
|---|---|---|
| **发行商** | 真实资产、法律权利、赎回条款、定期 attestation | 新的融资需求入口；资产不离开自己的合规框架 |
| **资金方** | USDC / USDT | 超额抵押的借贷收益；白名单准入 |
| **借款人** | 代币化商品抵押 | 以商品持仓借稳定币，不必卖出 |

## Planet 交付什么

1. **资产接入**：白名单、参数（LTV、清算阈值、估值源）、赎回条款链接。
2. **估值与风险分级**：多源价格（发行商赎回价 / 市场成交价）+ PPI 交叉校验；风险状态 normal / caution / frozen 直接映射到 LTV。
3. **撮合与记账**：供需两侧的池子、利率、清算触发。
4. **运营与报告**：抵押率、清算记录、数据质量事件的可审计日志。

## 风控怎么定 LTV（与通用借贷池的差别）

```
riskState normal   → 基准 LTV
riskState caution  → LTV 下调（行情源降级或资产被标记）
riskState frozen   → 禁止新增借款，仅允许还款与补充抵押
清算               → 外部场所变现，协议不自建 AMM、不持库存
```
参数由治理设定、经 timelock 生效；初始 MVP 只接入一类抵押品（代币化黄金）、只借出 USDC。

## 商务模式

| 收入项 | 说明 |
|---|---|
| 撮合费 | 借贷利差的一部分 |
| 接入费 | 发行商资产上架的尽职与配置 |
| 风控服务费 | 估值、监控、报告的持续服务 |

## 现在的状态（不夸大）

- PPI 指数已在 Arbitrum One 主网运行（14 商品、2-of-3 签名、风险状态）。
- 抵押借贷产品处于**规格阶段**：合约未部署、未审计、未开放任何存款。
- 之前的永续与 PLT 已停止并从站点下架，池子从未有过存款。

## 我们要什么

- **发行商**：一类可接入的资产（PAXG / XAUT / 代币化黄金 ETF 份额优先），以及赎回条款与 attestation 的访问方式。
- **资金方**：一次 20 分钟电话，确认风险偏好与准入流程。

## 合规边界（先说清楚）

借贷撮合在多数辖区需要牌照或与持牌方合作；本产品不构成存款、不承诺收益。具体结构以目标司法辖区的法律意见为准（待确认）。
