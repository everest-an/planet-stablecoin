# Planet — RWA Collateral Marketplace（路线 B）产品规格 v0.1

2026-11 · 战略转向：停止永续市场与 PLT 代币层；转向「代币化资产的抵押与借贷层」。
本文件是规格，不是宣传；所有未验证项标「待确认」。

## 一、定位

**The Collateral Layer for Tokenized Commodities.**
让不同发行商的合规代币化资产（优先大宗商品与商品 ETF）获得统一的抵押与融资能力。

Planet 不发行资产、不托管底层、不做资金池的最终风险承担者，而是做**接入、组合、估值、风控与撮合**。

## 二、角色分工

| 角色 | 负责什么 | 不负责什么 |
|---|---|---|
| 发行商 | 真实资产、法律权利、赎回条款 | 借贷撮合、风控 |
| 托管机构 | 底层资产保管与审计 | 链上抵押参数 |
| **Planet** | 资产接入、组合、估值、抵押参数、风险分级、撮合 | 发行、托管、自营方向性头寸 |
| 资金方 | 提供 USDC/USDT 流动性 | 资产筛选 |
| 借款人 | 抵押代币化资产、借出稳定币 | 定价 |

## 三、业务模型（用户原话落地）

```
客户（借款人）：抵押代币化商品 / 商品 ETF（如 PAXG、XAUT、代币化黄金 ETF 份额）
出资方（ lender）：存入 USDT / USDC
Planet：撮合借贷 + 估值 + 风控 + 清算规则
收入：撮合费（借贷利差的一部分）+ 接入费 + 风控服务费
```

关键：**Planet 不成为所有资产的发行商**——这是与 MakerDAO 式路线（路线 A）的根本区别，也是不需要「先让市场相信我们的币」的原因。

## 四、MVP 范围（P1）

| 决策 | MVP 取值 | 理由 |
|---|---|---|
| 抵押品类别 | 仅代币化黄金（PAXG / XAUT / 代币化黄金 ETF 份额，按可接入性排序） | 流动性最好、估值最统一、监管最清晰 |
| 借出资产 | 仅 USDC | 单一结算资产，避免汇率与多币种清算复杂度 |
| 抵押率 | 超额抵押；初始 LTV 由数据质量决定（见下） | 与现有 PPI 风险状态直接挂钩 |
| 利率 | 供需驱动 + 治理上下限 | 不做固定利率承诺 |
| 清算 | 外部场所（DEX/CEX）变现，协议只做触发与结算 | 不自建 AMM，不持有库存 |
| 准入 | 白名单（发行商 + 借款人地区） | 合规前置，不是无许可池 |

### 数据质量定价（复用既有能力）

这是与 Aave Horizon 类产品的差异点：**同一抵押品在不同数据状态下有不同 LTV**。

```
riskState = normal   → 基准 LTV（例如 70%）       待确认：具体数值
riskState = caution  → LTV 下调一档（例如 −10pp）
riskState = frozen   → 禁止新增借款；仅允许还款与补充抵押
```

估值源优先使用可验证的市场价（发行商赎回价 / 主流场所成交价），PPI 指数与风险状态作为**交叉校验与降级触发器**，而不是唯一价格。

## 五、需要的新组件

| 组件 | 作用 | 工作量级 |
|---|---|---|
| `CollateralRegistry` | 资产白名单、每资产参数（LTV、阈值、预言机源、赎回条款链接） | 小 |
| `LendingPool` | 供需两侧记账、利率模型、份额化出资 | 中 |
| `PriceAdapter` | 多源估值（发行商价 / 市场价 / PPI 交叉校验）+ 风险态输出 | 中 |
| `LiquidationEngine` | 触发、外部变现、坏账记账（不做内部 AMM） | 中 |
| `ComplianceGate` | 白名单、地区限制、发行商条款钩子 | 小（但法务前置） |

旧合约处理：`PPIPerp`、`PLT` 停止推广并从站点下架；`PlanetCore`（PPI 指数）保留为估值与风险层。

## 六、差异化（必须回答「凭什么是我们」）

| 对手 | 他们的强项 | 我们的切口 |
|---|---|---|
| Aave Horizon | 品牌、流动性、成熟清算 | 多发行商聚合 + **数据质量定价** + 大宗商品专长 |
| Morpho | 参数可定制、机构友好 | 同上；且我们提供资产接入与估值服务，不只是市场 |
| 发行商自营借贷 | 资产独家 | 跨发行商组合抵押（一篮子商品抵押借稳定币） |

**一句话**：别人做「通用抵押池」，我们做「大宗商品抵押的接入与风险层」——卖方是发行商，买方是资金方，我们赚撮合与风控。

## 七、风险与合规边界（待确认项集中区）

- 待确认：借贷业务在目标司法辖区的牌照要求（借贷牌照 / 证券法 / 商品衍生品边界）。
- 待确认：代币化商品的「法律权利」由发行商还是托管方承担；Planet 只做技术接入是否能规避发行责任。
- 待确认：清算时在外部场所变现的合规路径（尤其涉及证券型代币）。
- 待确认：KYC/AML 由 Planet 做还是由资金方做。
- **不做**：不发行资产、不托管底层、不做自营方向性头寸、不做稳定币。

## 九、与旧产品的关系

- **PPI 指数**：保留。作为抵押品估值交叉校验与数据质量信号。
- **永续市场（PPIPerp）**：停止。站点下架，自动化任务停用，合约保留但不再推广。
- **PLT 代币**：停止。未铸造、无储备，不再提及为产品。
- **金属路由（/metals）**：保留为获客入口，与路线 B 共用「代币化商品」叙事。
