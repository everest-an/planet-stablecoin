# 经济模型 / 资产真实性 / 价格成立性 —— 老实说

> 你问的三个问题：「经济模型真的成立吗？资产真实吗？价格成立吗？」
> **结论先行：不成立（作为"经济体"），资产不真实，价格只对了一半。** 以下是逐条依据。
> 关联：`docs/real-asset-1to1.md`、`docs/peg-stability.md`、`docs/mainnet-readiness.md`（Gate）。

## 1. 资产真实吗？—— **不真实（零背书）**

| 事实 | 位置 |
|---|---|
| 「存款」是**消息体字段** `Mint.amount`，不是真收到的价值；合约只收 TON 当 gas | `planet_core.tolk` `handleMint` |
| `totalReserve` 是**账面整数**，背后**没有任何 USDC/RWA/实物** | `Storage.totalReserve` |
| 铸出的 PLT 是**无抵押的合成代币**（真被 Jetton 铸出） | `JettonMinter` |

**结论**：当前 PLT = **零背书合成指数代币**。README/白皮书确有声明（"PoC、不含真实储备、非足额抵押"）——**声明诚实，但产品本身没有资产**。

> ⚠️ `EC1`（审计报告）= 这就是主网硬门槛。修复它 = 真的托管资产（托管方 + 储备证明 + 合规）；不是改几行代码。

## 2. 价格成立吗？—— **指数真，代币价不成立**

**成立的一半（数据侧 ✅）**：PPI 由**真实行情**（Yahoo+Sina 中位数）驱动，链上验签，重算加权指数——**数据是真的**。

**不成立的一半（市场侧 ❌）**：
1. **PPI ≠ PLT 的价格。** PPI 是"一篮子商品的加权价位"，PLT 的**市场价**要由买卖决定——而**我们没有任何交易所/流动性**（"不自建 DEX"，也没上任何 venue）→ **PLT 没有市场价**。
2. **基价（锚）是某一天单源快照**：`basePrice` 来自部署时一次 Yahoo 收盘价 → 指数"1.0"的锚点是任意的。
3. **签名阈值=1**：目前只有一把 relayer 钥（`threshold=1`）→ 数据可信度取决于这一把钥（可升 M-of-N，但现在是 1-of-1）。

**结论**：**指数是真实数据；但"PLT 值多少"未定义（无市场）。**

## 3. 经济模型成立吗？—— **作为"经济体"不成立；作为"机制仿真"成立**

**稳定/套利闭环要求两个前提，我们都没有：**
- (i) **PLT 有交易场所**（才能：PLT < 指数时买入→赎回套利；PLT > 指数时铸→卖）；
- (ii) **赎回真能兑出价值**（储备得是真的）。

→ 缺了 (i)(ii)，**所有稳定机制都是"空转"**：
- 分档费 / 费率斜率 / 非对称赎回 → 影响的是一个**不存在的市价**；
- 套利返利（`SetArb`）→ 没有套利者/场所；
- 稳定债券（C3b）/ 风险基金 → 吸收的是**无人支付的抛压**；分账 30/50/20 的桶**没有接收方**（无 staker、无回购场所）。

**更根本的**：当前**铸造近乎免费**（mock）→ 可无限印 → **代币无稀缺、无价值**。

**结论**：经济模型**在纸面/机制层自洽**（工程上正确实现），但**作为"能运转的经济"不成立**。它是**一套机制的仿真**，不是**一个经济体**。

## 4. 怎样才能"成立"（三条诚实路线）

| 路线 | 内容 | 代价 |
|---|---|---|
| **A. 真 1:1** | 真托管商品/ETF/USDC；储备真实；赎回兑实物/法币 | 托管方 + 储备证明 + 合规 + 审计（重，受监管） |
| **B. 超额抵押合成** | 用户锁抵押品→铸合成敞口（类 Synthetix/Dai） | 架构大改；需清算/预言机/资本效率设计 |
| **C. 定位为"指数/积分"** | 不承诺锚定；PLT = 追踪/奖励/积分代币 | 放弃"稳定币"叙事（最诚实、最快） |

> **现在的最诚实定位 = C（且 README 已如此声明）**。要做 A/B，是**产品级重构**，不是迭代。

## 5. 风险与红线（务必看）

- 🔴 **不可主网/不可上币**：一个**无背书、无市场、价格未定义**的代币若对外发行，**法律（证券属性）与信任风险极高**。
- 🔴 **EC1** 未解前，"deposit USDC"式文案会**误导用户**（App 已加 testnet 提示，但仍需强化）。
- 🟡 **单钥**（owner/relayer）→ 多签 + 时间锁 + 密钥分离（合约已就绪，运营待做）。
- ✅ 值得肯定的：**机制实现扎实、数据真实、11 项安全问题已修、TON 特有陷阱已避**——作为**技术 PoC** 是成功的。

## 6. 一句话总结

> **资产不真实（零背书）；价格只真一半（指数真、市值无）；经济模型作为机制自洽，作为经济体不成立。**
> 要"成立"，必须先在 A（真 1:1）/ B（超额抵押）/ C（明确定位为指数/积分）中**做出选择**，并补齐对应外部依赖。**在此之前，只能作为技术 PoC 展示，不能作为可交易/可持有的资产对外发行。**
