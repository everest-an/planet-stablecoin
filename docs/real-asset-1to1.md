# 从「合成指数代币」到「1:1 真实资产」—— 路线与前置条件

> 状态：设计稿。回答"如何变成真实资产 1:1"。
> 关联：`docs/PRD.md` §2（版本区分）、`docs/AUDIT.md`（信任模型）、`docs/PRODUCT-DESIGN.md`。

## 0. 一句话

现在 PLT 是**合成指数代币**（无实物兜底，`totalReserve` 是 **mock 记账**）。
"1:1 真实资产" = **每个 PLT 对应真实持仓（ETF/期货/实物）的按比例索取权**，由持牌托管方持有；
这不是"改几个合约"，而是**补一整个法律/托管/申赎/合规层**——技术只是其中一环。

## 1. 差在哪（现状 vs 目标）

| 维度 | 现状（合成） | 1:1 真实资产 |
|---|---|---|
| 底层 | 无 | SPV/基金持有 ETF/期货/实物，受监管托管 |
| 铸币 | 记账加 `totalReserve`（mock） | 收 USDC → 由 AP/协议**真实买入**篮子 → 托管 → 铸 PLT |
| 赎回 | 记账减 | **真实卖出**篮子 → 付 USDC（in-kind 或 in-cash） |
| 锚定 | 市场 + 软机制 | **create/redeem 套利**为主（ETF 式）+ 软机制为辅 |
| 信任 | 代码 | 代码 + **托管 + 审计 + 牌照** |
| 准入 | 无许可 | 通常**许可制**（KYC/AML，属证券/商品基金） |

## 2. 必须补齐的 5 层（缺一不可）

1. **法律主体**：SPV/基金（能合法持有商品/证券），注册地选择（开曼/BVI/瑞士/新加坡…取决于牌照与税务）。
2. **托管/经纪**：受监管经纪商（如 Interactive Brokers）或 RWA 托管方持有实际 ETF/期货；签托管协议。
3. **申赎机制（AP 模型，ETF 式）**：
   - **Creation**：授权交易商(AP) 交 USDC → 协议按目标权重买篮子 → 铸 PLT（扣申赎费）。
   - **Redemption**：AP 交 PLT → 卖篮子 → 付 USDC（或 **in-kind** 实物篮子）。
   - AP 的**申赎套利**是 1:1 锚定的主机制。
4. **储备证明 + 审计**：每日持仓快照 → Merkle 上链 + 第三方审计（见 `AUDIT.md`）；可加实时 NAV 预言机。
5. **合规**：KYC/AML、证券/商品法规、转让限制（可能许可制代币）、反洗钱、制裁筛查。

## 3. 技术侧改动（相对现有 TON 实现）

**好消息**：核心合约大部分可复用（PPI、铸赎、预言机接缝、稳定机制）。
需要新增：

| 改动 | 说明 |
|---|---|
| **NAV/储备预言机** | 托管方/审计方签名推送真实持仓价值（用我们已有的**签名更新**接缝 `SetSigner`/`SignedPriceUpdate`）→ 链上可验 1:1 覆盖率 |
| **授权交易商角色** | `SetDealer(addr, allowed)`；仅 AP 可走大额 create/redeem（其余走二级/permissionless 小额） |
| **KYC 钩子** | 铸/赎前校验白名单（链上映射或与合规服务联动） |
| **储备覆盖率校验** | `require(totalReserve >= totalSupply * targetNAV)`，由 NAV 预言机喂入 |
| **in-kind 赎回** | 或仅 in-cash（简化，先落地） |
| **暂停/限额/多签+时间锁** | 已部分实现；1:1 版需更严 |
| **真实 USDC 托管** | 现在无真实资产 custody；需 USDC 金库 + 提现授权流程 |

（现状里 `totalReserve` 是数字；1:1 版它必须等于**托管实盘 NAV**，且可验证。）

## 4. 分阶段路线（判断：能否成，取决于第 1 步）

| 阶段 | 内容 | 前置/阻塞 |
|---|---|---|
| A | 找**托管/经纪 + 法律结构**（jurisdiction、牌照评估） | 外部合作 + 资金 + 法务 |
| B | **小规模试点**：真实买入一篮子 ETF，每日审计，**许可制**铸造/赎回收少数 KYC 用户 | A 完成 |
| C | 接入 **creation/redemption（AP）** 与链上储备证明/NAV 预言机；第三方审计 | B 跑通 |
| D | 扩大规模、in-kind 赎回、多签治理、市场化稳定机制 | C 审计通过 |
| E | （若合规允许）逐步开放准入 | 监管路径 |

## 5. 现实与取舍（必须对用户讲清）

- **1:1 有储备的稳定币/基金通常是"许可制"**（KYC + 可能转让限制），不是无许可 DeFi——**去中心化程度与合规不可兼得**。
- **成本**：托管费、交易费/滑点、审计、法务、做市、市场时间（ETF 只在交易时段成交）。
- **对手方风险**：托管方违约/冻结；需分散 + 保险 + 法律隔离。
- **监管定性**：更可能被认定为**证券/商品基金份额**，而非"稳定币"；名称与话术须相应调整。
- **没有这 5 层，"1:1" 只是话术**——正是项目当初设红线的原因（不无实物却宣称足额抵押）。

## 6. 与现有机制的关系

- 1:1 版的**锚定主力是申赎套利**；我们已实现的**分档费/费率斜率/稳定债券/风险基金/CAM/风控**仍有价值：
  - 处理申赎摩擦、极端行情缓冲、费用分配、单商品故障隔离。
- 换言之：**1:1 是"再叠加法律+托管+申赎"到我们已建好的协议骨架上**，而非推倒重来。
