## 摘要

Planet（PLT）是一个**链上全球大宗商品购买力指数协议**。它把一篮子全球主流大宗商品（能源、金属、
农产品、工业原料）的价格聚合为统一的链上 **购买力指数 PPI**，并以合成代币 **PLT**（TON 上的 TEP-74）承载。

> **关键区分**：当前版本是**跟踪 PPI 的合成指数代币**，**不是** 1:1 实物储备的算法稳定币。
> 完整版需要真实链下储备（RWA）+ 合规背书，见 §6 路线图。

---

## 1. 背景与问题

- 单一商品（黄金、原油）波动大、敞口集中；传统多品类大宗商品投资门槛高、难以链上化。
- 通胀对冲需求上升，但缺少「一个代币 = 一篮子全球商品购买力」的公开、可验证工具。
- Telegram 生态（9 亿+ 用户）里，Mini App 只能用 **TON + TON Connect**（Telegram Blockchain Guidelines）——
  这决定了 Planet 的入口与链选择（TON）。

---

## 2. 定位与红线

- **定位**：「链上全球大宗商品购买力指数协议」，叙事**不是**「稳定币」。
- **红线**（不可动摇）：
  1. 早期版本是合成指数代币，**无实物兜底**，市价可能大幅偏离 PPI，须处处披露。
  2. 不碰链下期货自营；不早期冲 CEX；不刷量；不伪造喂价。
  3. 禁止「足额抵押 / 无风险锚定」话术；对外一律用「指数代币 / 合成指数 / 跟踪 PPI」。
  4. **不自建 DEX/AMM/订单簿**（交易交给外部场所）。

## 3. 核心机制

### 3.1 购买力指数 PPI（**已实现**）
```
PPI = Σ_i  w_i · (P_i / P_base_i)        // 全 1e6 定点，链上 computePpi 计算
```
- 篮子（权重/基准价/现价）存于核心合约；预言机/适配器推送**单资产价格**，核心**链上重算** PPI。
- 权重和须 = 100%；基准价可锁定（不可变）。

### 3.2 铸造与赎回（**已实现**）
```
Minted   = D · (1 − f) / PPI
Received = B · PPI · (1 − f)
```
- 费率分配：**45% 回购销毁 / 30% 储备 / 25% 质押分红**。
- **赎回链路**：用户钱包 `AskToBurn`（TEP-74）→ 铸币合约减供应 → **镜像通知核心**同步记账（供应以
  JettonMinter 为唯一真相源）。

### 3.3 稳定机制（**部分已实现**）
- **分档费**（已实现）：近锚 0.5%；偏差 3–5% 为 1%；>5% 为 2%；>15% **自动冻结铸币**。
- **单笔限额**（已实现）：`SetLimits`。
- **弹性铸赎曲线**（设计）：>5% 后费率线性陡峭化；下行非对称（赎回排队/限额）。
- **套利入口**（设计）：方向正确时返还部分手续费，激励外部套利者把价拉回 PPI。
- **稳定债券 + 风险基金**（设计）：`PPI<0.95` 折价发债，回收 PLT、吸收抛压。
- 详见 `docs/peg-stability.md`。

### 3.4 CAM 适配层（**Phase A 已实现**）
- 每类商品一个 **CAM**（Commodity Adapter Module），向核心输出**标准化**的
  `price / volatility / liquidity / riskState`。
- 核心据此：**风险自适应再平衡**（frozen 不调仓、高波动/低流动性抬阈值）、分级熔断/限额。
- 收益：新增/下线商品不改核心；**单一商品故障被隔离**。详见 `docs/commodity-cam.md`。
- **接入方式**：注册 CAM/适配器地址（`SetCam`）或**签名更新**（`SetSigner` + `SignedPriceUpdate`，链上 ed25519 验签）——接真实数据源只需**一个公钥**或 adapter 地址。

### 3.5 个体隔离与风险传导（**核心安全设计**）
- **逻辑 / 合约层解耦，不改链下托管**：底层期货 / ETF 仍在经纪商；解耦发生在**合约层**——CAM 作为每类
  商品的适配器做**校验与状态标记**，主协议只消费**标准化结果**（正常价格 / 警告 / 冻结），不直接对接原始喂价。
- **三态**：`normal` / `caution`（警告）/ `frozen`（冻结）。
- **frozen 的三重效果**：
  1. **不再参与 PPI 计算**（PPI 按**剩余有效资产重归一化**）；
  2. RTRA 再平衡**暂停对该资产调仓**；
  3. 其错误价格**不污染全局指标**。
- **风险向上传导（传导的是“状态”，不是“错误”）**：主协议据 CAM 状态调整**全局参数**——分档手续费、
  铸赎限额、分级熔断。
- **效果**：单一品种出现价格异常 / 数据源故障 / 流动性危机时，可**单独冻结或降权**；其余十几类商品照常运行，
  **协议整体继续工作**，避免单点错误直接污染全局 PPI、进而让整个稳定币系统承担过大的连锁风险。
- **二级市场**：仍交给**外部 DEX**，协议本身**不做交易所**。

## 4. 架构（分层）

```
L0 储备 / RWA      实物/ETF 储备 + 托管 + 储备证明                      [未来]

L3 稳定 / 风控      分档费 · 弹性曲线 · 套利入口 · 债券 · 风险基金 · 熔断 [部分已实现]
（不自建 DEX/AMM；交易走外部场所）
```

## 5. 风险与合规

- **偏离锚定**：合成版无实物兜底，市价可能大幅偏离 PPI。
- **预言机**：TON 第三方喂价覆盖/可用性需评估；已有时间戳防重放与范围校验。
- **流动性**：冷启动深度不足，价格易被操纵。
- **合规**：开启真实铸赎将构成金融产品（需牌照/托管）；当前刻意规避。
- **机制边界**：稳定机制为**软稳定**（激励/债券），不替代真实储备。

## 7. 治理（规划）

- **PLTG**：治理代币（总量固定），承载参数投票、手续费分红、生态激励。
- **关键权限**：单笔限额、多签 + 时间锁、分级暂停；参数变更事件化、可追溯。
