# Planet 稳定机制设计（借鉴 DL-AMM 思想，**不自建 DEX**）

> 状态：**设计稿（未实现）**。
> **前提**：Planet **不做 DEX/AMM**。所有交易发生在**外部** DEX/场所；本文只**借鉴**离散流动性 /
> 限价单 / 区间激励的**机制设计思想**，用来**加固稳定币协议本身**（铸赎、费率、激励、熔断、债券）。
> 关联：`docs/PRODUCT-DESIGN.md`（架构）、`docs/commodity-cam.md`（CAM）、`docs/ppi-multiasset.md`（PPI）。

## 0. 定位与边界

- **不做**：自建交易所、订单簿、AMM 池、LP 代币。
- **做**：在协议内部用"借鉴来的机制"让 PLT **更快回归 PPI、抗操纵、抗挤兑**。
- 交易层交给外部 DEX；协议只负责**发行/赎回/费率/激励/熔断**。

## 1. 借鉴清单 → 协议机制映射

| DL-AMM 的设计思想 | 借鉴到 Planet 协议（**非**池子） |
|---|---|
| 离散 tick | 用**分档带（bands）**定义 PPI 偏差 → 不同档位不同费/激励/限额（替代连续公式） |
| 目标附近用常数和 | 铸赎**定价曲线**在 PPI 附近近似 1:1（低摩擦），偏离时**陡峭化**（抑制脱锚，弹性供应） |
| 集中流动性（锚附近） | 把**激励/支持**集中在"锚附近有效带"（不全局撒币） |
| 内置 tick 限价单 | **免许可套利接口**（`arbMint`/`arbBurn` + 微激励）→ 让**外部套利者**主动把价拉回 PPI |
| OneSide 单边模式 | PPI 大幅跳变 → 切**非对称模式**（单方向吸收 / 非对称调费 / 暂停一侧） |
| LiquidBox 只奖励有效区间 | 只奖励**恢复锚定的行为**（带内 mint/burn、认购稳定债券），而非全局激励 |
| CAM 动态调参 | CAM 的 `volatility/liquidity/riskState` → 调**协议参数**（费档/阈值/限额/熔断），不是池子 tick |

## 2. 具体机制设计

### 2.1 分档费用（band fees）
- 依 `PPI` 距 1.0 的偏差分档（例：`|Δ|≤3%` 基准费；`3–5%` 提高；`>5%` 更高/暂停）。
- 目标区间**低摩擦**（鼓励贴近锚的套利），远离区间**惩罚性**（抑制脱锚交易）。

### 2.2 铸赎定价曲线（near-peg 常数和近似）
- 在 `PPI ∈ [0.97,1.03]`：铸赎近似 `1 PLT ≈ PPI`（**低滑点**，弹性供应）。
- 超出区间：**非线性陡峭**（越远越贵，抑制进一步脱锚）；可叠加**赎回排队/限额**防挤兑。

### 2.3 免许可套利入口（借"限价单"思想的协议版）
- 提供 `arbMint(to)` / `arbBurn()`：当市价 > PPI，套利者 mint（压价）；市价 < PPI，套利者 burn（抬价）。
- **不做订单簿**；只是给套利者一个**低成本、可组合**的入口 + 微激励，缩短脱锚持续时间。

### 2.4 分级熔断（CAM 驱动）
- CAM `riskState`：`normal` 正常；`caution` 提高费/降限额；`frozen` **暂停该资产相关操作**（并告警）。
- 全局暂停（已实现 `paused`）+ 单笔/窗口限额（规划）。

### 2.5 稳定债券（Stabilization Bond）
- `PPI < 0.95`：折价发行债券（以未来**手续费/风险基金**偿还），**回收 PLT、吸收抛压**、缓冲下行。
- 优先级与偿付来源须明确（见开放问题）。

### 2.6 风险基金
- 来源：手续费的储备份额（已实现 30% 记账）+ 债券收益；用途：极端情形缓冲、债券偿付。

### 2.7 再平衡路由（走外部场所）
- RTRA 计算的 `ΔA_i` 调仓**优先路由到外部 DEX/场所**，分批成交降滑点；**不自建池**。

## 3. 为什么更安全（收益）

- **缩短脱锚时间**：套利入口 + 弹性供应曲线让价格更快回归。
- **缓冲下行**：稳定债券 + 风险基金吸收抛压。
- **隔离与熔断**：CAM 逐资产 `riskState` → 单商品故障不影响全局（见 `commodity-cam.md`）。
- **抗操纵**：分档费 + 范围校验 + 时间戳单调 + `frozen` 熔断。
- **激励精准**：只奖励恢复锚的操作，减少被刷。

## 6. 深化：弹性铸赎曲线（参数化）

**目标**：近锚 ≈1:1（低摩擦），偏离时**非线性陡峭**（抑制脱锚），且 mint / redeem **非对称**。

设偏差 `d = PPI − 1e6`（ppm），`ad = |d|`。费用（bps）分档 + 斜率：

```
feeBps(ad) =
  50                                   , ad ≤ 30_000            (≤3%)
  100                                  , 30_000 < ad ≤ 50_000   (3–5%)
  200 + SLOPE·(ad − 50_000)/1e6        , ad > 50_000            (>5% 线性陡峭)
```
- `SLOPE`（建议初值 1000 bps/1.0 偏差，即每偏离 100% 加 10% 费）；**已实现前三档**，斜率项为下一步。
- **非对称**：`PPI<0.97`（下行）时赎回费上调 + 赎回**排队/限额**防挤兑；`PPI>1.03`（上行）时赎回费下调（鼓励退出、回收 PLT）。
- 铸币公式（已实现）：`Minted = D·(1−f)/PPI`；赎回：`Received = B·PPI·(1−f)`，`f=feeBps/1e4`。

**参数表（建议初值）**

| 参数 | 值 | 说明 |
|---|---|---|
| `BAND_LOW` | 3% | 基准带边界 |
| `BAND_HIGH` | 5% | 高档带边界 |
| `SLOPE` | 1000 bps | >5% 后的线性费率斜率 |
| `REDEEM_QUEUE_PPI` | 0.97 | 低于此值赎回排队 |
| `REDEEM_CAP_PER_TX` | 上限 | 赎回单笔限额（复用 `SetLimits`） |

## 7. 深化：稳定债券偿付模型

**触发**：`PPI < 0.95`（下行脱锚），用于**回收 PLT、吸收抛压**。

**机制**：用户以 **PLT 认购债券**（PLT 被销毁/锁仓），获得**未来偿付凭证**；偿付来自**未来手续费**（储备桶 + 回购销毁桶）。

```
认购：  用户付 PLT_amount  → 收到 Bond{ face, maturity, principal_ppi }
定价：  face = PLT_amount · PPI_target · (1 + premium)
        premium = PREMIUM_BASE · (0.95e6 − PPI) / 1e6   （偏离越大，折价越高）
偿付瀑布（优先序）：手续费储备桶 → 债券持有人（按 maturity 排队）→ 风险基金 → 质押分红
```

- **上限**：总发行 `BOND_CAP`、单地址上限、到期阶梯（分批，避免集中兑付）。
- **偿付来源**：手续费 30% 储备桶 + 45% 销毁桶（不依赖融资）。
- **兜底**：手续费不足 → 展期（maturity 顺延）或由风险基金补足；**不承诺固定回报**（合规红线）。

**参数表（建议初值）**：`PREMIUM_BASE` ≈ 5%（最大折价）；`BOND_CAP` = 当前供应 × 10%；`MATURITY` 90–180 天阶梯。

## 8. 深化：套利入口激励设计

**目标**：让**外部套利者**主动把市价拉回 PPI（Planet **不自建 DEX**）。

**方向假设**（链上只知 PPI，不知市价，故按 PPI 偏差给激励）：
- `PPI > 1.03`（理论上市场偏贵）→ 奖励 **mint**（增供给、压价）。
- `PPI < 0.97`（理论上市场偏贱）→ 奖励 **burn/赎回**（减供给、抬价）。

**激励形式**：满足方向时，**返还部分手续费**（如 50%）或给 PLTG 奖励（来自费用池，非融资）：
```
rebate = fee_cap · REBATE_BPS/1e4        , 方向与偏差一致且在激励带内
```
- **防刷**：仅当 `ad ≥ 3%` 才计酬（避免近锚白嫖）；每地址/每 epoch 上限；TWAL 加权；与 `SetLimits` 协同。
- **注意**：这是**近似**机制（无法链上验证"确使市价收敛"）；属于**软稳定**，不替代储备/债券。
