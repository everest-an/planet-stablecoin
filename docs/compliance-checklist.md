# 合规 / 托管 / 券商 —— 落地清单（给律师与托管方）

> 用途：把"**能不能合规地做这支代币化 ETF 基金**"变成一张**可逐条推进/勾选**的表。
> **这是决定成败的门槛（不是代码）。** 关联：`positioning-v2.md`、`tokenized-etf-fund.md`、`fund-contract-design.md`。
> ⚠️ 非法律意见；须由**持牌律师**就具体辖区出具意见。

---

## A. 定性：PLT 是什么？（**先回答这个**）

- [ ] **证券/基金份额定性**：多数辖区，代表"一篮子 ETF 份额"的 PLT = **集合投资计划份额 / 证券**。
      需按**基金/证券法**注册或豁免。
- [ ] **管辖地**：客户在哪、运营在哪、托管在哪、发行主体在哪？（决定适用哪套法）
- [ ] **豁免路径**：是否有可行豁免（如仅专业投资者、私募、特定辖区）？
- [ ] **代币属性**：是"权益凭证"还是"债权"？是否附带投票/分红？
- **产出**：一份**法律定性备忘**（Memorandum）。**没有它，不要对外发**。

## B. 基金结构（三选一）

- [ ] **① 持牌公募基金**（如 UCITS 型）：面向零售，成本最高，最正规。
- [ ] **② 私募/专业投资者基金**（Cayman/BVI/开曼 SP 等）：门槛高但合规清晰。
- [ ] **③ 仅合格投资者（Accredited/Professional）**：范围小、合规成本低。
- **决策**：目标客户是谁 → 决定结构 → 决定牌照与成本。

## C. 托管（**必须有，且要可验证**）
- [ ] **托管方**：持牌托管/银行，或受监管的券商托管账户。
- [ ] **资产隔离**：客户资产与运营方自有资产**严格隔离**（破产隔离）。
- [ ] **ETF 买卖执行**：券商账户 + 交易授权 + 成交/持仓对账。
- [ ] **储备证明（PoR）**：定期（如月度）**第三方 attestation**，最好链上可验。
- [ ] **再平衡**：目标权重、容忍带、执行规则（可复用 `shouldRebalance` 思路）。

## D. KYC / AML / 适当性
- [ ] 客户**身份核验（KYC）** + **反洗钱（AML）** + 制裁筛查。
- [ ] **适当性**：风险揭示、投资经验/承受力评估。
- [ ] **链上挂钩**：Fund 合约 `kycRequired` + `allowed` 白名单（仅放行通过者）。
- [ ] 法币**出入金**通道（银行/支付）+ 记录留存。

## E. 信息披露 / 募集
- [ ] **募集说明书（Prospectus）/ PPM**：投资目标、篮子、费用、风险、赎回条款。
- [ ] **费率披露**：管理费、申赎价差、其它成本——**清晰透明**。
- [ ] **风险揭示**：市场会跌、可能亏损本金、托管/操作/合规风险。
- [ ] **NAV 披露**：频率与计算口径（净费后）。

## F. 运营与治理
- [ ] 运营主体 + **基金治理**（投资决策、再平衡授权）。
- [ ] **多签 + 时间锁**管理链上权限（`owner` = 多签 + `PlanetTimelock`）。
- [ ] **托管密钥 = M-of-N**（托管 + 运营 + 独立第三方）。
- [ ] 审计与合规监察（Compliance Officer）。
- [ ] 应急预案（暂停申赎、NAV 异常、托管方故障）。

## G. 技术侧对接（与本项目对应）
- [ ] `PlanetFund` 合约：**入金 + 托管确认**后铸币（修 `EC1`）、NAV 护栏、两阶段赎回、费率。
- [ ] 托管签名设施：**M-of-N + 域分隔 + 单调时间戳**（复用现有）。
- [ ] PoR / NAV attestation 的**链上可验证**格式。
- [ ] 第三方**智能合约审计**（上主网分界线）。

---

## H. Go / No-Go 门槛（缺一不可）

**可以对外发行/募集的必要条件：**
1. [ ] **法律定性备忘** + **合适结构**（B）
2. [ ] **持牌托管 + 资产隔离 + PoR**（C）
3. [ ] **KYC/AML + 适当性**（D）
4. [ ] **募集说明书 + 风险揭示**（E）
5. [ ] **第三方合约审计通过**（G）
6. [ ] **多签 + 时间锁 + 密钥分离**（F）

**在此之前：只能作为测试网 PoC 展示，不得对外募资/发行/持有。**

## I. 要问律师的 10 个问题
1. 在 [辖区]，代表 ETF 篮子的代币是"证券/基金份额"吗？
2. 有无**豁免**路径（专业投资者/私募/小额）？
3. 发行主体建在哪、什么形态（基金/SPV/信托）？
4. 需要哪些**牌照**？周期与成本？
5. 代币**可转让**是否改变定性？
6. 分红/再投如何处理？
7. 跨境客户（尤其美/欧/中）各自的限制？
8. 托管与资产隔离的**法律要求**？
9. PoR 与 NAV 披露的**合规口径**？
10. 营销/募集的**红线**（哪些话不能说）？
