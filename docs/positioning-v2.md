## 0. 一句话

**Planet 让任何人用一枚代币，持有一篮子全球 ETF 指数——你买 PLT，我们替你真实买入并托管 ETF，
按净值（NAV）记账，收管理费；篮子涨，你就赚。**

## 1. 为什么改定位（老实说）

| | v1/v1.5：合成指数稳定币 | **v2：代币化 ETF 基金** |
|---|---|---|
| 资产 | ❌ 无背书（凭空铸） | ✅ 真 ETF（托管） |
| 客户为何赚钱 | ❌ 说不清（无市场/无兑付） | ✅ 篮子涨就赚（真资产） |
| 我们赚什么 | ❌ 费用桶空转 | ✅ 管理费 + 申赎价差 |
| 监管 | 复杂模糊 | **明确（它是基金/证券，需要牌照）** |

> 改定位不是"换个说法"，是**把产品从不成立改成成立**——代价是要**合规做基金**。

## 2. 是什么 / 不是什么（v2）

**是什么**
- 一支**链上登记份额、可 7×24 申购赎回**的 **ETF 篮子基金**。
- PLT = **基金份额**，按 **NAV（每份净值）** 定价；底层是**真实持有的 ETF**。
- 运营方 = **基金管理人**（选篮子、再平衡、托管、合规），赚**管理费**。

**不是什么**
- ❌ **不是**"算法稳定币"，**不承诺** 1 PLT = 固定价格。
- ❌ **不是**无抵押的合成代币（v1 的问题，v2 从根上修）。
- ❌ **不是** DEX/交易场所本身（份额可在外部分发/交易，但 Planet 不自建撮合）。
- ❌ **不是**"保本/保收益"产品——**篮子会跌，客户会亏**。

## 3. 产品流程

```
1) 客户入金(USDC/法币) → 申购 PLT
2) 运营方用这笔钱，按目标权重真实买入一篮子 ETF → 进托管账户
3) 托管方 attest 持仓价值 → 链上 NAV
4) 按 NAV − 申购费，铸 PLT 给客户
5) 赎回：烧 PLT → 卖对应 ETF → 按 NAV − 赎回费付款
6) 每日：NAV 更新；定期：再平衡 + 储备证明
```

## 4. 经济模型（成立的那个）

- **客户收益** = 篮子 ETF 的资本利得 + 分红再投（**真涨真赚**）。
- **运营方收益** = **管理费**（AUM × 年费率，如 0.5–2%）+ **申赎价差**（0.1–0.5%）+ 再平衡返佣。
- **风险**：市场风险（篮子会跌）、托管/操作风险、合规风险——**全部如实披露**。

## 5. 架构

- **链上（TON）**：`PlanetFund` = 份额登记 + NAV + 申购/赎回 + 收费 + KYC 白名单；
  PLT = TEP-74 份额；托管签名 = **M-of-N**（`fund-contract-design.md`）。
- **链下**：券商/托管、ETF 买卖与再平衡、储备证明、KYC/AML、法币出入金。
- **治理**：owner = **多签 + 时间锁**。

## 6. 现状 vs 路线

| 阶段 | 内容 | 状态 |

| **P1（现在）** | 链上机制 PoC（指数/铸赎/风控/安全加固）——**技术底子** | ✅ 已实现、已审计加固、测试网 live |

## 7. 路线图（v2）

1. 定位落地：官网/白皮书/App 改口为"ETF 基金（PoC）"（**进行中**）。
2. `PlanetFund` 合约（两阶段申购 + NAV 护栏 + 确认后铸币，**修 EC1**）→ 单元测试 → 端到端。
3. 赎回 + 费率/NAV 计提。
4. 链下：券商/托管打通 + 储备证明。
5. **合规**：牌照 + 募集说明书 + KYC/AML（**决定性**）。
6. 第三方审计 → 小额试点 → 放量。
