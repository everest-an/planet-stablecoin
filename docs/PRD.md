## 1. 产品概述

Planet 是一个部署在 **Solana** 链上的「全球大宗商品购买力指数」协议。它把一篮子（目标 20+ 种）全球主流大宗商品（能源、金属、农产品、工业原料）的真实市场价格，通过链上预言机聚合为一个统一的 **购买力指数 PPI（Purchasing Power Index）**，并以链上合成代币 **PLT** 的形式承载该指数的价值。

- **PLT**：跟踪 PPI 指数的合成交易代币（早期定位为「链上大宗商品 ETF 指数」，不是足额抵押稳定币）。
- **PLTG**：治理代币（总量固定 10 亿），承载协议参数投票、手续费分红与生态激励。

> 核心区别（必须公开、反复声明）：
> **本协议当前版本 ≠ 白皮书完整版「1:1 大宗商品储备的算法稳定币」。** 完整版需要外部 RWA 托管方 + 真实链下 ETF/期货储备 + 合规背书，零融资小团队无法一步到位。当前产品是「跟踪 PPI 的合成指数代币」，其价格由二级市场 DEX 交易决定，**没有链下实物资产兜底，市场价可能大幅偏离理论 PPI**。

## 2. 版本区分（信任底线，不可混淆）

| 维度 | 早期版本（当前） | 完整版（未来） |
|------|------------------|----------------|
| 名称 | **PLT-index** 指数代币 | PLT 稳定币 |
| 底层资产 | 无（纯链上合成） | 1:1 大宗商品期货/ETF 真实储备 |
| 铸造/赎回 | 无真实实物赎回；仅 DEX 二级市场交易 | 存入 USDC ↔ 换取/赎回真实储备份额 |
| 储备托管 | 无 | 受监管经纪商（如 Interactive Brokers）+ RWA 托管方 |
| 价格锚定 | 市场驱动，参考 PPI | 动态再平衡 + 弹性供应维持 ≈ PPI |
| 合规 | 合成指数衍生品 | 金融产品（需牌照/托管/审计） |
| 当前状态 | **开发中** | 待外部合作落地后启动 |

> **红线**：任何对外材料、网站、文档、社区话术，一律使用「指数代币 / 合成指数 / 跟踪 PPI」的表述，**禁止**宣称「1:1 实物储备」「足额抵押稳定币」「无风险锚定」。误导用户会引发法律与声誉灾难。

## 3. 目标用户

### 3.1 加密交易者（主）
- 想对冲美元通胀、做多「一篮子」大宗商品，而不愿单独买原油、黄金反复调仓的用户。
- Solana DEX 生态的链上散户 / DeFi degens。

### 3.2 RWA 研究者与开发者（辅）
- 关注「实物资产映射链上」机制设计的 RWA 研究者、大宗商品交易爱好者。
- 潜在未来合作方（RWA 托管商、审计机构）——通过代码开源、运行历史记录建立信任。

> 现阶段**不面向机构**：机构不认可没有真实储备的版本。

---

## 4. 产品定位与叙事

- 差异化：市面上链上大宗商品多为单一品种（黄金、原油），Planet 是 **多品类全球大宗商品购买力指数**。
- 叙事关键词：**「链上全球大宗商品购买力指数协议」**，不是「稳定币」。
- 核心价值主张：一个代币，跟踪全球真实商品购买力，规避单一经济体通胀风险。

## 5. 功能需求

### 5.1 阶段一：Solana 测试网概念验证（0–3 月）【当前开发范围】

**目标**：把白皮书全部算法在测试网跑通，产出可信 demo，用于建社区、吸引开发者与未来合作方。

功能需求：

| 编号 | 功能 | 描述 | 优先级 |
|------|------|------|--------|
| F1.1 | 价格预言机接入 | 对接 Pyth（devnet），读取大宗商品实时价格，带 staleness + 置信区间校验 | P0 |
| F1.2 | PPI 计算模块 | 链上实现 `PPI_t = Σ w_i · (P_i,t / P_i,base)`，权重可配置 | P0 |
| F1.3 | 储备状态管理 | 链上账户存储各商品权重、基准价、当前持仓价值、总储备规模 | P0 |
| F1.4 | RTRA 再平衡模拟 | 计算每商品理论调仓量 `ΔA_i = (w_i − V_i/ΣV) × T`，写入链上日志（**不执行真实 DEX 交易**） | P0 |
| F1.5 | 模拟铸造 / 赎回 | mock 存入 USDC → 铸造 PLT、销毁 PLT → 赎回 USDC，均扣 0.5% 手续费 | P0 |
| F1.6 | 静态价格回退 | 支持本地静态价格源（`StaticPriceFeed`），使单测/demo 不依赖 Pyth 也能跑 | P0 |
| F1.7 | 极简前端 | 展示实时 PPI、各商品权重、模拟再平衡日志、手续费流向 | P1 |
| F1.8 | 开源 | 代码全部开源到 GitHub，注释完整 | P0 |
| F1.9 | 演示物料 | 测试网演示视频 + 更新版白皮书（明确区分测试网版 vs 未来主网实盘版） | P1 |

**阶段一明确不做（Out of Scope）**：
- 不执行真实 DEX 撮合交易（测试网合成 token 无真实流动性）。
- 不接真实链下储备、不碰期货保证金。
- 不做 DAO 治理、不做真实代币销售。

### 5.2 阶段二：Solana 主网发行 PLT-index（3–8 月）

| 编号 | 功能 | 描述 |
|------|------|------|
| F2.1 | PLT-index 发行 | Token-2022（带 `TransferFee` 扩展，0.5% 转账费）部署主网 |
| F2.2 | PLTG 发行 | 总量 10 亿；团队 2 年锁 + 3 年线性；mint 权限 revoke |
| F2.3 | 初始流动性 | 自有少量 USDC-PLT 建 Raydium CPMM 池；LP 销毁 |
| F2.4 | 手续费分配 | 45% 回购销毁 / 30% 协议金库 / 25% PLTG 质押分红（金库仅来自手续费，不依赖融资） |
| F2.5 | PLTG 获取 | 仅通过 LP 挖矿质押 PLT-index/USDC 获得，团队不预挖抛售 |
| F2.6 | 公开看板 | 实时 PPI、商品权重、Pyth 源价格、手续费流向、金库余额 |
| F2.7 | DEX 集成 | 接入 Jupiter 聚合器，保证可交易性 |
| F2.8 | 风险提示 | 网站/文档显著声明：指数交易代币，非足额抵押稳定币 |

### 5.3 阶段三：向完整版 PLT 稳定币演进（8 月后，需外部资源）

| 编号 | 功能 | 描述 |
|------|------|------|
| F3.1 | RWA 托管对接 | 找 RWA 服务商负责链下购买/管理 ETF；协议负责链上合约 + PPI 算法 |

## 6. 非功能需求

| 编号 | 类别 | 要求 |
|------|------|------|
| N1 | 性能 | 交易确认 < 0.5s；手续费 ≈ $0.00025（Solana 原生） |
| N2 | 安全 | 数学运算全用 checked_* 防溢出；Pyth 置信区间校验；CPI 限制防重入 |
| N3 | 透明度 | 链上储备地址公开可查；所有参数变更可追溯 |
| N4 | 可审计 | 第三方审计（Halborn）；形式化验证（Certora） |
| N5 | 可维护性 | 代码开源、注释完整、模块化 |

## 7. 风险与免责声明

1. **偏离锚定风险**：PLT-index 无底层实物兜底，市场价格可能大幅偏离理论 PPI。必须在所有触达点显著披露。
2. **合规风险**：若未来开启真实铸造/赎回，将构成金融产品，需牌照与托管背书；当前阶段刻意规避。
3. **预言机风险**：Pyth 大宗商品 feed 覆盖不全（见 PLAN），价格更新延迟/异常需兜底。
4. **流动性风险**：冷启动期 DEX 深度不足，价格易被操纵。
5. **免责声明**：本协议为技术提案，不构成投资建议；大宗商品价格波动可能导致 PLT 短期偏离锚定。

## 8. 成功指标（阶段一）

- [ ] 测试网合约部署成功，全部算法跑通。
- [ ] PPI 计算与白皮书公式一致（可复算验证）。
- [ ] 单测覆盖核心算法，`anchor test` 全绿。
- [ ] 代码开源、注释完整。
- [ ] 演示视频 + 更新版白皮书产出。
- [ ] 50–100 名种子用户（DeFi 开发者 / RWA 研究者 / 大宗商品爱好者）。

## 9. 范围外（Out of Scope，全阶段）

- 团队自营期货交易（展期/保证金/爆仓风险，禁止）。
- 早期冲 CEX 上币。
- 购买虚假社群 / 刷虚假交易量。
- 任何「足额抵押稳定币」的虚假宣传。
