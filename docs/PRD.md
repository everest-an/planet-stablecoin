## 1. 产品概述

Planet 是部署在 **TON** 链上的「全球大宗商品购买力指数」协议。它把一篮子全球主流大宗商品
（能源/金属/农产品/工业原料）的价格，经**适配层**标准化后聚合为链上 **购买力指数 PPI**，
并以合成代币 **PLT**（TEP-74）承载。

- **PLT**：跟踪 PPI 的**合成指数代币**（早期，非足额抵押稳定币）。
- **PLTG**：治理代币（规划中），承载参数投票、手续费分红与生态激励。

> **核心区别（必须反复声明）**：本协议当前版本 **≠** 白皮书完整版「1:1 大宗商品储备的算法稳定币」。
> 当前是**跟踪 PPI 的合成指数代币**，无链下实物兜底，市场价格可能大幅偏离理论 PPI。

**分层架构（详见 PRODUCT-DESIGN.md）**：L0 储备/RWA（未来）· L1 `PlanetCore`（已实现）·
L2 CAM 适配层（设计）· L3 DL-AMM 市场层（设计）· L4 稳定机制（设计）。

## 2. 版本区分（信任底线，不可混淆）

| 维度 | 早期版本（当前） | 完整版（未来） |
|------|------------------|----------------|
| 名称 | **PLT-index** 指数代币 | PLT 稳定币 |
| 底层资产 | 无（纯链上合成） | 1:1 大宗商品期货/ETF 真实储备 |
| 铸造/赎回 | 存入 USDC ↔ 铸/赎 PLT（合成，无实物兑付） | 存入 USDC ↔ 换取/赎回真实储备份额 |
| 价格锚定 | 市场驱动，参考 PPI | 动态再平衡 + 弹性供应维持 ≈ PPI |
| 合规 | 合成指数衍生品 | 金融产品（需牌照/托管/审计） |

> **红线**：一律使用「指数代币 / 合成指数 / 跟踪 PPI」表述，**禁止**「1:1 实物储备」「足额抵押稳定币」「无风险锚定」。

## 3. 目标用户

- **加密交易者（主）**：想对冲美元通胀 / 做多一篮子大宗商品、不愿单独反复调仓的用户；TON/Telegram 生态用户。
- **RWA 研究者与开发者（辅）**：关注实物资产映射链上机制、通过代码开源建立信任。
- 现阶段**不面向机构**（无真实储备，机构不认可）。

---

## 4. 产品定位与叙事

- 差异化：市面多为单一品种（黄金/原油），Planet 是**多品类全球大宗商品购买力指数**。
- 叙事关键词：**「链上全球大宗商品购买力指数协议」**，不是「稳定币」。
- 入口：**Telegram Mini App**（获客即发行）。

## 6. 非功能需求

| 编号 | 类别 | 要求 |
|------|------|------|
| N1 | 数值安全 | 定点 1e6；中间量用 257-bit `int` 防溢出；无浮点 |
| N2 | 存储约束 | 单 cell ≤1023 bits；超限放 ref cell |
| N3 | 安全 | 关键权限多签 + 时间锁；全局暂停；限额 |
| N4 | 透明度 | 链上篮子/PPI/供应/费率公开可查；参数变更事件化 |
| N5 | 可审计 | 第三方审计 + 形式化验证 + 漏洞赏金 |
| N6 | 可维护性 | 开源、模块化、测试覆盖 ≥ 门槛（当前 90%） |

## 7. 风险与免责声明

1. **偏离锚定**：PLT-index 无实物兜底，市价可能大幅偏离 PPI。须处处披露。
2. **合规**：开真实铸赎将构成金融产品，需牌照/托管；当前刻意规避。
3. **预言机**：TON 上 RedStone/DIA 覆盖与可用性需评估（见 `oracle-ton.md`）；已有时间戳单调 + 范围校验。
4. **流动性**：冷启动深度不足，价格易被操纵。
5. **自研市场层风险**：DL-AMM 为重大自研，安全/审计成本极高；**不建议早期上主网**（见 PRODUCT-DESIGN §6.2）。
6. **免责声明**：技术提案，不构成投资建议。
