# 商品指数永续（PPI-Perp）— 设计文档

2026-10-29. 一个不存在于这个时代的衍生品：**以多商品指数为标的、由 LP 池充当对手方、用预言机置信度
驱动保证金**的永续合约。它同时解决本项目最大的结构性缺陷（H-02：储备不随指数增长）。

---

## 0. 先承认那道墙

任何衍生品都必须回答一个问题：**谁在另一头？**

| 产品 | 对手方 | 为什么我们做不了 |
|---|---|---|
| 指数期权 | 做市商 | 需要专业 MM 和库存 |
| 通胀挂钩债券 | 承保方垫本金 | 需要资本 + 牌照 |
| 参数化保险 | 承保池 | 需要承保资本 |
| 结构化产品（保本票据） | 发行人垫本金 | 同上 |

**唯一的例外：永续合约。** 永续的对手方是**流动性池**，池子的钱来自 LP —— 而 LP 之所以愿意，
是因为他们赚交易费和资金费。**这是一个不需要我们先有钱的衍生品结构。**

---

## 1. 设计：PPI-Perp

### 1.1 交易的是什么

标的不是单一商品，而是 **PPI —— 14 种商品的多资产指数**（我们已有，链上、四渠道、带置信度）。
这是世界上第一个**多商品指数永续**。单一商品永续（原油、黄金）在 GMX/Hyperliquid 上有零星几个；
**商品指数永续，一个都没有。**

### 1.2 三个结构（这是它"没出现过"的地方）

**(a) LP 池当对手方，收取资金费**
交易者做多/做空 PPI，池子接单。池子由 USDC 组成，按份额分配盈亏与手续费。净多头时，多头付资金费给池子；
净空头反之。资金费 = (永续标记价 − 指数)/指数，每 8 小时结算。

**(b) 资金费流向指数持有者 —— 这一步解决 H-02**
传统永续的资金费只给 LP。我们把它拆开：**资金费的 70% 分给 PLT（指数代币）持有者**。
效果：PLT 持有者除了持有指数，还收到"做多商品的投机者付的 carry"。
这意味着 —— **储备第一次能赚到接近指数涨幅的收益**，而不需要持有实物商品或 ETF。
这就是白皮书 §1.2 说"没有任何费率表能修复、只有正确的储备才能"的那个问题的**另一种解法**：
不换储备，让储备去赚投机者的钱。

**(c) 保证金由预言机置信度驱动 —— 我们的独有资产**
我们的预言机有 `riskState`（正常/警戒/冻结）和 `confirmations`（几个渠道相互确认）。
PPI-Perp 用这个信号调整保证金：

```
confirmations ≥ 2  →  正常杠杆（最高 10x）
confirmations = 0  →  保证金要求 +50%，禁止新开仓
riskState = 冻结   →  只允许平仓，不允许新开
单资产被拒价 > 1%  →  该资产权重临时归零，指数重算
```

**没有任何交易所用"数据质量"来定保证金。** 这是它真正的护城河：当油价的四个渠道打架时，
我们的永续会自动收紧，而不是等清算引擎在坏价上炸掉一片仓位。

### 1.3 为什么有人来交易（需求侧）

- **通胀投机者**：想赌"大宗商品要涨"，但不想选单一商品、不想开商品期货账户。一个指数 = 一篮子通胀敞口。
- **对冲者**：持有实物/股票/矿业股的人，想用指数空头对冲通胀反转。
- **套利者**：PPI-Perp 与单商品永续之间的价差（我们已有套利用户画像：叮当那群人）。
- **LP**：赚交易费 + 资金费，且用 `riskState` 信号决定何时撤流动性 —— 这是他们第一次能"按数据质量"管理风险。

## 2. 收入模型（这才是"我们也赚钱"）

| 来源 | 费率 | 说明 |
|---|---|---|
| 开/平仓费 | 0.05%–0.10% | 主流永续水平，走量 |
| 资金费分成 | 30% 归协议，70% 归 PLT 持有者 | 协议拿三成，剩下的把指数代币变成有收益的资产 |
| 清算罚金 | 清算额的 1%，50% 归协议 | 标准结构 |
| 指数授权 | 其他协议用 PPI 做标的，收 bps | 第二阶段 |

**关键：这是流量生意（手续费）+ 浮存生意（资金费）的合体。** 我们此前争论的"MakerDAO 还是 Circle"
在这里被绕过了 —— 不需要资本，因为 LP 提供资本；不需要托管，因为标的是指数不是实物。

## 3. 与现有产品的分工

```
PLT（指数代币）     储蓄端：持有商品敞口，收资金费 carry        ← 白皮书的目标形态
PPI-Perp            交易端：给投机者杠杆，给 LP 费用            ← 新增
/metals             入口：看持仓、买金银、法币换算               ← 已有
```

三者闭环：/metals 带来用户 → 用户持有 PLT → PLT 收 carry → 投机者来交易 → 手续费和资金费回流。

## 4. MVP 路径（诚实版：先不碰真钱）

| 阶段 | 做什么 | 时间 |
|---|---|---|
| 0 | 纸面交易（testnet，无真钱），验证资金费/清算公式 | 2 周 |
| 1 | 单商品（黄金）永续，1 个 LP 池，限额 $10k | 3 周 |
| 2 | 三商品指数，接入 riskState 保证金 | 4 周 |
| 3 | 完整 14 资产指数 + PLT carry 分成 | 待审计后 |

**不做的事**：不做现货交割、不做杠杆超过 10x、不对散户开放超过监管允许的辖区。

---

## 5. 诚实风险（这是它可能死的地方）

1. **冷启动流动性**：新永续最大的死因不是技术，是没有做市商。必须先有 LP，再有交易者。
   缓解：LP 收益来自资金费 + 手续费，前 30 天用协议金库补贴（需资本）。
2. **预言机操纵**：指数由 4 个渠道构成，操纵成本高于单源，但仍可能。缓解：riskState 门槛 +
   单次价格变动上限 + 延迟清算。
3. **衍生品监管**：永续合约在多数辖区对散户受限。必须先做非受限辖区 + 专业用户，或等牌照。
   这是唯一可能否决整个产品的硬约束。
4. **PLT carry 的可持续性**：如果市场长期净空头，资金费方向反转，PLT 持有者反而要付钱。
   缓解：carry 只在净多头时分配，净空头时留在池子里。

## 6. 为什么不是别的（已排除）

| 方案 | 为什么不选 |
|---|---|
| 商品指数期权 | 需要专业做市商库存，我们没有 |
| 通胀挂钩债券 | 需要承保本金，我们没有 |
| 参数化价格保险 | 需要承保资本池，我们没有 |
| 黄金红包 | 需要托管（红包在领取前是托管），违背原则 |
| 用黄金付款 | 黄金是储蓄资产，没人花自己的对冲 |
| 商品预测市场 | 长尾 100+ 协议分 1.65% 交易量，进去就死 |

**永续是唯一"对手方由 LP 自愿提供、不需要我们先有资本"的衍生品结构。** 而"多商品指数 + 置信度
保证金 + 资金费回流指数持有者"这三件事组合起来，是今天链上不存在的。

> **世界上第一个用"数据置信度"定保证金的多商品指数永续 —— 投机者付的资金费，直接变成指数持有者的
> 通胀保护收益。**

这句话如果能成立，它就不是"又一个 DEX"，而是一个新的资产类别。
