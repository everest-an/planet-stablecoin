## 1. 项目一句话

面向代币化大宗商品的抵押借贷市场：借款人抵押 PAXG/XAUT 等代币化商品，出借人提供 USDC；协议负责资产接入、估值、抵押率与清算规则。指数与风险态在 Arbitrum 计算，签名喂价跨链到抵押所在链。

## 2. 审计范围（4 个文件，约 800 行 Solidity 0.8.24）

| 文件 | 职责 | 关键风险面 |
|---|---|---|
| `CollateralRegistry.sol` | 资产白名单、LTV/caution-LTV/清算阈值、价格源接口 | 参数边界、禁用资产语义、失败安全 |
| `LendingPool.sol` | 存贷记账、债务指数、利用率利率、清算、坏账核销、白名单与暂停、重入锁 | 会计不变量、清算数学、坏账社会化、重入、取整 |
| `SignedFeedAdapter.sol` | 跨链 2-of-3 签名喂价（每资产一个实例），陈旧→冻结 | 签名重放/可锻性、链 ID 绑定、时间戳 |
| `PPIFeedAdapter.sol` | 把指数（PPI + 风险态）转成价格源 | 陈旧判定、未来时间戳、指数为 0 |

**不在范围**：`PlanetCore` 指数合约（已单独自审）、测试用 Mocks、前端、跨链桥（本方案不使用桥）。

## 3. 设计摘要（给审计员）

- 抵押价值 1e18 USD；债务 1e6（USDC），比较时 `USD_SCALE = 1e12`
- 清算规则：`debt > Σ collateral × liqThreshold` 可清算；任一价格源冻结时，只有「超出阈值 50%」的仓位可清算
- 坏账路径：抵押价值 < 债务时，清算人付可回收部分、取走全部抵押，差额写入 `BadDebt` 并从 `totalSupplyAssets` 扣除（出借人按份额承担）
- 风险分级：normal → 基准 LTV；caution → 下调 LTV；frozen → LTV 0（禁止新借）
- 安全开关：白名单、暂停（不阻断还款/提款/清算）、每资产抵押上限、全局债务上限
